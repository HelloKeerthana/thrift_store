
# 🧵 OnceUponAfind – Online Thrift Store 🌸

Welcome to **OnceUponAfind**, a chic and sustainable online thrift store where fashion meets conscious living. 
Browse through curated preloved pieces, discover hidden gems, and embrace slow fashion with a modern web experience.

---

## 💡 About the Project

**OnceUponAfind** is a full-stack web application designed to make thrifting fun, accessible, and aesthetically pleasing. 
Built by a passionate team of developers, the platform is clean, easy to navigate, and focused on promoting conscious consumerism.

---

## 🔧 Tech Stack

### 🖥️ Frontend
- **HTML5** & **CSS3**
- **Bootstrap** – For responsive styling and grid layout
- **JavaScript** – For interactive client-side behavior
- **Jinja2** – Template rendering with Flask

### 🧠 Backend
- **php**
- **jspdf** (for bill receipts)

### 🗃️ Additional Tools
- **Git** & **GitHub** – Version control and team collaboration
---

## ✨ Features

## ✨ Features

- 🛍️ **Browse Listings** – View a variety of second-hand fashion items
- 📂 **Category Pages** – Easily navigate between men's and women's sections
- 🎨 **Modern UI** – Clean, stylish interface with responsive layout
- 📝 **Download Catalog (PDF)** – Export selected listings using **jsPDF**
- 💖 **Wishlist System** – Save your favorite items to revisit later
